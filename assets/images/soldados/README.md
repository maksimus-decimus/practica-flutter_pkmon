# Assets de Soldados

Coloca aquí los sprites de los soldados. Necesitas 6 imágenes en total:

## Archivos necesarios:

### Aliados (3 tipos):
- `aliados_mg.png` - Soldado con ametralladora (tanque)
- `aliados_rifle.png` - Soldado con rifle (balanceado)
- `aliados_asalto.png` - Soldado de asalto (DPS alto)

### Eje (3 tipos):
- `eje_mg.png` - Soldado con ametralladora (tanque)
- `eje_rifle.png` - Soldado con rifle (balanceado)
- `eje_asalto.png` - Soldado de asalto (DPS alto)

## Recomendaciones:
- **Tamaño**: 128x128 píxeles o 256x256 píxeles
- **Formato**: PNG con fondo transparente
- **Estilo**: Pixel art, ilustraciones o sprites realistas
- **Orientación**: 
  - Soldados aliados mirando hacia la DERECHA →
  - Soldados del eje mirando hacia la IZQUIERDA ←

## Fuentes de sprites gratuitos:
- [OpenGameArt.org](https://opengameart.org/) - Busca "soldier sprites"
- [Itch.io](https://itch.io/game-assets/free) - Assets gratuitos
- [Kenney.nl](https://kenney.nl/) - Sprites de calidad gratis
- [CraftPix](https://craftpix.net/freebies/) - Assets 2D gratuitos

## Características de cada tipo:

### Ametralladora (MG)
- Más resistente (150 PS)
- Icono: Escudo 🛡️
- Colores: Verde/Marrón

### Rifle
- Balanceado (100 PS)
- Icono: Rayo ⚡
- Colores: Azul/Gris

### Asalto
- Frágil pero letal (80 PS)
- Icono: Fuego 🔥
- Colores: Rojo/Naranja

## Ejemplo:
Si no tienes sprites, el juego mostrará iconos de colores por defecto.
