# Assets de Banderas

Coloca aquí las imágenes de las banderas de las facciones:

## Archivos necesarios:
- `aliados.png` - Bandera de los Aliados (ej: USA, UK, etc.)
- `eje.png` - Bandera del Eje (ej: Alemania Nazi, etc.)

## Recomendaciones:
- **Tamaño**: 300x200 píxeles (relación 3:2)
- **Formato**: PNG con fondo transparente
- **Calidad**: Buena resolución para verse bien en pantalla

## Fuentes de imágenes gratuitas:
- [Flaticon](https://www.flaticon.com/) - Busca "flag icons"
- [Freepik](https://www.freepik.com/) - Busca "world war 2 flags"
- [Pixabay](https://pixabay.com/) - Imágenes libres de derechos
- Puedes usar emojis de banderas convertidos a imágenes

## Ejemplo simple:
Si no tienes imágenes, el juego mostrará iconos por defecto.
